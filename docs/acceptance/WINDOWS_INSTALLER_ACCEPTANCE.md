## 1. Pre-Deployment Packaging & Native Picker Findings Remediated (`2026-11-20`)

1. **`electron-builder.json` Main Entrypoint Fixed (`W-003`)**: Previously lacked `"extraMetadata": { "main": "dist/main.cjs" }`, causing `npm run electron:build` to inherit `"main": "dist/server.cjs"` from `package.json` instead of Electron's `dist/main.cjs`. Fixed cleanly.
2. **`packaging/windows/build-installers.js` Native ABI Rebuild Added (`W-003`)**: Added `npx electron-builder install-app-deps` prior to NSIS compilation on Windows build hosts so native `better-sqlite3` matches Electron 43's Node ABI (preserving the non-Windows cloud guard `if (process.platform !== 'win32') process.exit(0)`).
3. **Enterprise Multi-Mode Inno Setup Specification Added (`packaging/windows/installer-config/installer-server-enterprise.iss`)**: Added explicit setup types for **Mode A (Server Only)**, **Mode B (Server + Desktop)**, and **Mode C (Single-PC Standalone)** passing `-InstallMode` directly to `install-ledgerai-service.ps1`, while strictly preserving `%ProgramData%\LedgerAI\data` and `%APPDATA%\LedgerAI` during upgrades and uninstallations (and preserving existing `installer-client.iss` with `installersVerification.test.ts` **9/9 PASS**).
4. **Open Pre-Build Packaging Requirement (`GAP-WIN-01`)**: 64-bit `nssm.exe` is not bundled in git (`electron-builder.client.json` also excludes `!tools/**/*`); Windows release engineering must place verified 64-bit `nssm.exe` into `tools\nssm.exe` when assembling the Windows Enterprise Server installer.
