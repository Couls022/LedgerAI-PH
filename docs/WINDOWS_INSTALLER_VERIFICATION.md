## 1. Native Compilation Technical Forensics

In the Linux container environment, attempting `electron-builder --win` produces:
```
• preparing       moduleName=better-sqlite3 arch=x64
⨯ node-gyp does not support cross-compiling native modules from source.
```

`better-sqlite3` is a C++ native Node addon utilizing `node-gyp`. Native compilation for Windows requires Microsoft C++ build tools and Windows SDK headers that cannot be cross-compiled inside a Linux container.

## 2. Windows Native Target Specifications & Build Requirements

To build and sign the official Windows installer on a native Windows machine:

### System Prerequisites
- **Operating System**: Windows 10 or Windows 11 (64-bit)
- **Node.js**: `v20.x` or `v22.x` (LTS)
- **npm**: `>= 10.x`
- **Electron Version**: `^43.4.0` (as defined in `package.json`)
- **Python**: Python 3.10+ (required by `node-gyp`)
- **C++ Compiler**: Visual Studio Build Tools (C++ Desktop Development workload) or Visual Studio 2022 with MSVC v143 and Windows 10/11 SDK.

### Build & Packaging Commands
From PowerShell (Administrator):
```powershell
# 1. Clone/extract repository export
cd /path/to/ledgerai-ph

# 2. Install dependencies
npm ci

# 3. Compile native dependencies for Electron target
npx @electron/rebuild -f -w better-sqlite3

# 4. Build frontend, server, and Electron main/preload
npm run build

# 5. Package Windows NSIS installer
npx electron-builder --win nsis --x64
```

### Expected Output Artifact
- **Target File**: `dist/installer/LedgerAI-PH-Setup-1.0.0.exe`
- **Architecture**: `win-x64`
- **Package Format**: NSIS Self-Extracting Installer

   - Confirm all accounting records, user accounts, and company profiles remain 100% intact.
6. **Uninstallation**:
   - Run `Uninstall LedgerAI PH.exe`.
   - Confirm application binaries are removed while database file `%APPDATA%\LedgerAI-PH\ledgerai.db` is preserved to protect tenant financial data.
