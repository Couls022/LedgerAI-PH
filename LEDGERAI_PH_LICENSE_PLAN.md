# LedgerAI PH - License Plan

## 1. Overview
LedgerAI PH implements a local, offline-capable licensing system. The software can be installed and activated in environments with zero internet connectivity.

## 2. Cryptographic Validation
- **License Keys/Files**: Licenses are cryptographically signed payloads (e.g., JWTs or custom signed JSON files) generated by the central authority.
- **Local Verification**: The local server contains the public key necessary to verify the signature of the license file/key. No outbound network request is strictly required to validate authenticity.

## 3. License Payload Details
The license payload contains embedded constraints:
- `company_name`: Licensed entity.
- `max_users`: Limit on concurrent or total registered users.
- `max_companies`: Multi-tenant limits.
- `modules`: Feature flags (e.g., `ocr_enabled: true`, `ai_enabled: false`).
- `expiry_date`: Hard expiration date.

## 4. Enforcement
The license is checked during server startup and periodically by a background worker. If a license expires or is invalid, the system enters a "Read-Only" mode. Users can still access and export their historical data, but cannot post new transactions until a valid license is applied.
